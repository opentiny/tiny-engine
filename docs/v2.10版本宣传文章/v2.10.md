# TinyEngine 2.10 发布：零代码 CRUD、云端协作，开发效率再升级！

TinyEngine 是一套**可定制化的低代码引擎**，让开发者能够通过可视化搭建页面，或通过 CLI 创建个人工程进行二次开发，定制出属于自己的低代码平台。它适用于资源编排、服务端渲染、模型驱动、移动端、大屏端、页面编排等多种场景。

近期，我们正式推出 **TinyEngine v2.10** 版本，带来了**模型驱动、登录注册与工作区、出码预览**等重磅特性，同时支持添加自定义 MCP 服务器扩展 AI 能力，对图表配置、画布交互等功能进行了深度优化。

## 核心特性详解

### 1. 模型驱动 - 零代码 CRUD，开发效率提升 80%

#### 背景与问题

在传统的后台管理系统开发中，创建一个包含表单、表格和完整 CRUD 功能的页面往往需要开发者：

- 重复配置相似的表单和表格组件
- 手动绑定数据源、编写事件处理逻辑
- 数据模型变更时，同步修改多个组件配置

这种重复性劳动不仅耗时，还容易出错。

#### 核心功能

**模型驱动特性**通过声明式的数据模型配置，自动生成对应的 UI 组件和数据交互逻辑，实现真正的"零代码"数据管理页面。

**四大核心模块**：

| 模块 | 功能 |
|------|------|
| 模型管理器插件 | 可视化创建数据模型、配置字段和 API |
| BaseForm 表单组件 | 基于模型自动生成表单 |
| BaseTable 表格组件 | 基于模型自动生成表格 |
| BasePage 页面组件 | 组合表单+表格，生成完整 CRUD 页面 |

**支持的字段类型**：String（字符串）、Number（数字）、Boolean（布尔）、Date（日期）、Enum（枚举）、ModelRef（关联模型）

#### 价值亮点

- **开发效率提升 80%**：通过配置模型即可生成完整的 CRUD 页面，无需手动配置每个组件
- **支持嵌套模型**：字段可关联其他模型，实现复杂数据结构（如用户关联部门）
- **标准化输出**：基于统一模型生成的 UI 组件保证了一致性
- **灵活扩展**：可自定义字段类型和组件映射

#### 使用场景

- 后台管理系统的数据管理页面
- 需要频繁进行增删改查操作的业务场景
- 需要快速原型的项目

#### 快速上手

1. 打开**模型管理器**插件，创建数据模型（如"用户信息"）
2. 配置模型字段（姓名、年龄、邮箱等）和 API 方法
3. 拖入 **BasePage** 组件到画布
4. 绑定模型，即可自动生成包含搜索、新增、编辑、删除、分页的完整页面

### 2. 登录注册与工作区 - 云端协作，多组织管理

#### 功能概述

TinyEngine v2.10 引入了完整的用户认证系统，支持用户登录、注册、密码找回，同时新增**应用中心**和**模板中心**，让您的设计作品可以云端保存、多设备同步、团队协作。

#### 登录注册

- **用户登录**：基于用户名/密码的身份认证，Token 自动管理
- **用户注册**：支持新用户注册，注册成功后提供**账户恢复码**用于找回密码
- **密码找回**：通过账户恢复码重置密码，无需邮件验证

**密码安全要求**：
- 长度 8-20 个字符
- 必须包含大小写字母、数字和特殊字符
- 不能有 3 个及以上连续相同字符

#### 应用中心

登录后进入**应用中心**，您可以：
- 查看所有已创建的应用
- 快速创建新应用
- 选择应用进入编辑器

![应用中心](./assets/app-center.png)

#### 模板中心

**模板中心**让您可以：
- 保存页面设计为模板
- 基于模板快速创建新页面
- 团队内共享设计资产

![应用中心 + 模板中心](./assets/app-template-center.png)

#### 组织管理

- **多组织支持**：用户可属于多个组织
- **组织切换**：动态切换组织上下文，组织间数据隔离
- **创建组织**：一键创建新组织，邀请团队成员加入

![组织切换](./assets/org-switch.png)

#### 核心价值

| 功能 | 未登录 | 已登录 |
|------|--------|--------|
| 保存设计 | 仅本地缓存 | 云端保存 |
| 多设备同步 | 不支持 | 实时同步 |
| 团队协作 | 不支持 | 支持 |
| 组织管理 | 不支持 | 多组织切换 |

### 3. 出码支持查看代码 - 导出前预览所见即所得

出码功能新增**源码预览**能力，用户在导出代码前可以实时查看生成的源码内容，提升代码导出体验和准确性。

#### 功能特性

- **左右分栏布局**：左侧树形文件列表，右侧 Monaco 代码编辑器预览
- **智能初始化**：打开对话框时自动显示当前编辑页面对应的文件代码
- **实时预览**：点击树形列表中的任意文件，即可在右侧预览其代码内容
- **灵活选择**：支持勾选需要导出的文件

#### 使用方法

1. 在编辑器中点击「出码」按钮
2. 左侧树形列表显示所有可生成的文件，当前页面对应文件自动展示在右侧
3. 点击任意文件预览源码，勾选需要导出的文件
4. 点击「确定」选择保存目录完成导出

![出码预览](./assets/code-preview.png)

### 4. 自定义 MCP 服务器 - 扩展 AI 助手能力

TinyEngine 之前已提供内置 MCP 服务，让 AI 可以调用平台提供的各种能力。v2.10 版本支持**添加自定义 MCP 服务器**，通过简单配置即可集成第三方 MCP 服务，扩展 AI 开发助手的工具能力。

#### 功能特性

- **灵活配置**：通过配置文件简单添加自定义服务器
- **协议支持**：支持 SSE 和 StreamableHttp 两种传输协议
- **服务管理**：在 AI 插件的配置界面管理 MCP 服务器的开关状态
- **工具控制**：可查看并切换各个工具的启用状态

#### 使用场景

您可以集成企业内部 MCP 服务、社区 MCP 服务、第三方 MCP 工具等，扩展 AI 助手的业务能力。例如，添加一个图片搜索 MCP 服务后，可以让 AI 生成带图片的页面。

## 功能优化

### 画布与 Schema 面板支持同步滚动

Schema 面板新增**"跟随画布"**功能，启用后当在画布中选中组件时，Schema 面板会自动滚动到对应位置并高亮显示。

- **快速定位**：当页面元素较多时，能快速找到对应组件的 Schema 配置
- **双向对照**：可视化视图与 JSON 代码视图对照，便于理解页面结构

**使用方法**：打开 Schema 面板，勾选面板标题栏的"跟随画布"复选框即可启用。

![Schema 面板跟随画布](./assets/schema-scroll.png)

### CSS 字段对象格式

页面 Schema 中的 CSS 样式字段由字符串格式优化为**对象格式**，提升样式配置的可读性和可维护性。系统会自动处理对象与字符串的相互转换，出码时自动转换为标准 CSS 字符串格式。

### 图表组件属性平铺展开

图表组件的配置面板优化，将原有的整体 options 配置拆分为独立的属性配置项（颜色、数据、坐标轴、图例、缩放、提示框、边距、主题），使配置更加清晰直观。

![图表组件属性平铺展开](./assets/chart-config.png)

### 其他优化

- 修复区块管理/页面管理预览失败问题
- 修复预览没有 token 的问题
- 登录页最小高度适配
- 优化应用中心/模板中心交互与 UI
- 调整 AI 搭建功能请求逻辑和交互
- 修复模型组件预览报错问题
